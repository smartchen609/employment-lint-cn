# 法律法规文本汇编

维护人（深圳执业律师）整理的劳动人事争议常用法律法规，2026-09-09 提供，
由 Word 文档转为纯文本后收入本目录。**手册引用条文以本目录文本为准。**

## 注意

- 部分文件的版本可能不是最新（文件名含修正年份的以文件名为准），
  维护人判断"总体影响不大"。手册引用时，`sources.yml` 里的
  `verification_record` 会注明维护人确认现行有效的日期。
- 广东高院 2008 / 2012 / 2017 / 2018 四份与深圳中院 2015 裁判指引，
  维护人 2026-09-09 确认仍在适用，个别条款的实务变化见各节说明。
- 2008–2013 年的最高法劳动争议解释（一）至（四）旧版已被 2020 年
  解释（一）整合，本目录保留作历史参考，手册不再引用。
