# 劳动者自助仲裁手册

> 七八十分的覆盖，一百分的来源。
> 公允到维护人代理公司方时也不觉得它偏。

## 写作约定

- **读者**：正在或即将与公司发生劳动争议的劳动者，不假设法律背景。第二人称。
- **每节结构固定**：这一节说什么 → 法律怎么规定 → 常见误解 → 实务分歧 → 你现在该做什么 → 你可能没想到的 → 类案参考 → 依据。
- **法条只引已核验来源**（`sources.yml` 中 `page_opened_and_checked: true`），引用时标 source_id，构建时校验。
- **实务分歧必须写两面**：写清两种立场各是什么、各自的理由，不替读者选。
- **不出现的表达**：与 `rules/copy` 相同的 §6.5 禁止清单（`稳了` `一定能拿` `成功率` ……）。守卫测试同样扫描本目录。
- **类案匿名**：只写事实结构与结果走向，不写公司、姓名、案号。
- **标记**：`[待核验]` 表示法律内容尚缺来源；`[维护人补充]` 表示需要律师提供的经验内容。
