# 07 · 证据：现在能取，以后取不到

> 状态：第一版，维护人 2026-09-09 审定。本节每段法条原文都能在「来源与核验」查到出处。

## 这一节说什么

前面每一节末尾都说"保存证据"。这一节集中讲：**哪些证据现在就要拿、哪些等离职就拿不到了、哪些不能拿。**

先说结论：劳动争议里最常见的失败不是法律理解错，是**证据没了**——账号关了、群退了、邮箱进不去了。而这些都是在解除生效那一刻发生的。所以证据固定要在你还在职、还有权限的时候做。

## 法律怎么规定

《劳动争议调解仲裁法》第六条：

> 发生劳动争议，当事人对自己提出的主张，有责任提供证据。与争议事项有关的证据属于用人单位掌握管理的，用人单位应当提供；用人单位不提供的，应当承担不利后果。

**这条的意思**，两半：

- 前半：你主张的，你举证。你说加了班，你得证明；你说有续订意愿，你得证明。
- 后半：**公司手里的，公司得拿出来。** 考勤系统、工资表、规章制度、内部审批——这些你拿不到是正常的，仲裁时要求公司提供，公司不提供就对它不利。

所以你的证据任务是：**你能拿到的现在拿；你拿不到但公司有的，记下来是什么、在哪个系统里**，仲裁时点名要。

## 四类情形的证据清单

每类分两栏：左栏现在还能拿，右栏离职后大概率拿不到。

### 一、合同到期与续订（对应第一节）

| 现在还能取得或主动形成 | 解除后很可能难以取得 |
| --- | --- |
| 全部劳动合同及补充协议，不只保存最后一份 | 公司邮箱中的续签审批、HR 往来及历史附件 |
| 原到期日、延长协议、自动续延条款 | HR 系统里的合同版本和续签流程状态 |
| 书面表达续订或继续工作的邮件、微信 | 内部组织架构、岗位编制和同岗位人员名单 |
| 公司不续签通知及送达记录 | 内部招聘页面及相近岗位信息 |
| 变更签约主体的通知、协议和原因 | 变更前后实际管理、考核、工资审批流程 |
| 到期后继续工作的考勤、发薪和工作成果 | 企业 IM、知识库、工单系统和项目历史 |
| 原岗位、地点、汇报关系连续的材料 | 能显示工作不中断的内部项目记录 |

### 二、单方解除与第四十条第三项（对应第二节）

| 现在还能取得或主动形成 | 解除后很可能难以取得 |
| --- | --- |
| 解除通知原件及全部版本 | 内部组织调整、岗位撤销和 AI 项目通知 |
| 公司最初给出的书面理由 | 调整前后的组织架构、人员名单 |
| 原岗位说明、劳动合同中的工作内容 | 仍在招聘或保留的相近岗位 |
| 公司提出的每一份调岗方案 | 内部岗位库、薪酬级别和岗位权限 |
| 与岗位、工资、地点、职责有关的沟通 | Jira、飞书、钉钉、Slack、内部 Wiki 中的项目分工 |
| 你对调岗方案的回复和替代建议 | Git 仓库中的 commit、PR、review 和任务记录 |
| 仅谈补偿而未谈岗位的记录 | 能证明原工作仍由同事、外包或新员工完成的材料 |
| 历史绩效、OKR、项目评价 | 解除后被关闭的邮箱、云盘和内部系统 |

### 三、被迫解除与欠薪（对应第三、五节）

| 现在还能取得或主动形成 | 解除后很可能难以取得 |
| --- | --- |
| 劳动合同中的工资约定 | 公司内部的工资核算表 |
| 银行流水（发放主体、金额、日期） | 工资系统中的应发明细 |
| 工资条、个税 App 里的收入记录 | 考勤系统原始数据 |
| 社保、公积金缴费记录（可自行查询） | 加班审批流程记录 |
| 打卡截图、加班安排的聊天记录 | 门禁、工位系统记录 |
| 你发出的被迫解除通知及送达凭证 | 公司收到通知后的内部处理记录 |
| 向公司催要工资的书面记录 | — |

### 四、事实解除与协商解除（对应问答工具的另外两个入口）

| 现在还能取得或主动形成 | 解除后 / 签署后很难恢复 |
| --- | --- |
| 权限被关闭的页面、时间和账号信息 | 账号后台状态及权限变更记录 |
| 公司拒绝入场、拒绝安排工作的文字 | 门禁、考勤和工位安排记录 |
| 书面表达仍愿意工作的消息 | 工作群、项目群及被移除记录 |
| 公司最初提出解除的邮件、聊天和会议纪要 | 谁先提出解除的原始沟通 |
| 每一版协议草案 | 草案修订记录和文件元数据 |
| 公司要求提交个人辞职的记录 | 签署过程中的口头承诺 |

## 证据边界：哪些不能拿

这一段对程序员尤其重要，因为你们手里往往有权限。

> 只保存与本人劳动关系、岗位、绩效和解除事实具有必要关联的材料。
> 不要绕过权限控制，不要使用他人账号，不要批量复制源代码、客户数据、模型权重、密钥、商业秘密或与案件无关的公司文件。
> 证据固定不等于可以无限制下载公司数据。

**具体说**：

- 你自己的合同、工资条、考勤截图、跟你有关的聊天记录——可以。
- 证明你的工作仍由别人在做的材料——可以截图**你正常权限内能看到的**，比如你还在的项目群里别人接手了你的任务。
- **不可以**：为了取证去翻别人的账号、导出整个代码库、拷贝客户名单、下载你权限外的文件。这不但可能让证据无效，还可能让你从劳动争议的原告变成另一个案子的被告。

拿不准的，宁可不拿，仲裁时依第六条要求公司提供。

## 怎么保存

- **截图带时间和上下文。** 单独一句话的截图不如整段对话；网页截图带地址栏。
- **原件优先。** 邮件用导出而不是截图；文件保存原始格式。
- **别只存在公司设备上。** 离职那天设备要交还。
- **发出去的通知留凭证。** EMS 单号、邮件已发送记录、微信发送时间。
- **按时间排一遍。** 入职、签合同、每次变动、解除——一条时间线，仲裁时你自己也清楚。
