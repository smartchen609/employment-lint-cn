# 事实模型

规则层（`rules/**.yml`）与引擎层（`src/engine/`）之间的契约。

**唯一真相是 `src/engine/fact-paths.ts`**，本文档解释它。
规则如果用了未声明的路径，`tests/rules.test.ts` 直接失败。

命名空间对齐 round2 §10.1 的 Case Export 字段结构，
这样导出报告与规则条件不会各说一套。

---

## 一、直接事实

来自用户回答，引擎不加工。分组与问题树的对应关系写在 `fact-paths.ts` 的注释里。

| 命名空间 | 来源 | 说明 |
| --- | --- | --- |
| `scope.*` | G03 | 主要劳动合同履行地，决定是否进入深圳分支 |
| `operation.*` | G01 | 五个入口形态之一 |
| `contract.*` | A01–A11 | 合同类型、次数、延长、自动续延、主体变更、规避安排 |
| `post_expiry.*` | A15–A15.5 | 期满后是否继续工作、公司是否后来解除 |
| `renewal.*` / `indefinite_term.*` | A12–A14 | 续订意愿、是否要求固定期限、法定排除事由 |
| `objective_change.*` | B03–B11 | 第四十条第三项四层条件的输入 |
| `procedure.*` | P02–P03 | 继续履行还是赔偿金、是否客观不能履行 |

## 二、派生事实

由引擎计算，**不由用户直接回答**。目前两项，都是期间计算。

| 路径 | 计算内容 | 使用者 |
| --- | --- | --- |
| `contract.extension.cumulative_calendar_months` | 协商延长累计的日历月数 | 深圳规则（`>6`）、全国第十条第一项（`>=12`） |
| `post_expiry.no_objection_exceeds_one_calendar_month` | 用人单位未表示异议是否超过一个日历月 | 《解释二》第十一条 |

### 期间计算的法律纪律

两项都必须走《民法典》第二百零二条的**日历月**规则：
到期月的对应日为期间最后一日；没有对应日的，月末日为最后一日。

**禁止实现为 `days > 30`。** CLAUDE.md §E4、round3 §3 A15.3。

`addOneCalendarMonth` 在本项目中属于法律规则，不是工具函数，
其依据已登记在 `CN-NAT-SPC-LABOR-II-11` 的 `legal_basis` 中。

边界测试（P3 必须全绿）：

```
2026-01-31 → 2026-02-28：未超过一个月
2026-01-31 → 2026-03-01：超过一个月
2026-08-31 → 2026-09-30：未超过一个月
2026-08-31 → 2026-10-01：超过一个月
```

## 三、求值顺序：引擎必须分两轮

有两个路径不是"用户回答"，而是**上一轮规则的产物**：

| 路径 | 由谁回填 |
| --- | --- |
| `contract.deemed_second_fixed_term` | 《解释二》第十条各项规则命中后回填 |
| `findings.unlawful_termination_candidate_present` | 定性阶段产生违法解除／终止候选后回填 |

因此 P3 的引擎不能一轮跑完，结构应当是：

```
第一轮 · 定性规则
├── 第十条第一至四项（四类视同情形，必须并行检测）
├── 第十一条（与第十条并行，不得命中第十条即停止）
├── 深圳第十八条第二款（与全国规则并行展示，不互相覆盖）
├── 第四十条第三项三条规则
└── AI 解释信号
        ↓ 回填 contract.deemed_second_fixed_term
        ↓ 回填 findings.unlawful_termination_candidate_present
第二轮 · 义务与救济规则
├── 劳动合同法第十四条（无固定期限订立义务）
├── 第四十八条（继续履行 / 赔偿金的替代性选择）
└── 第八十七条（赔偿金路径）
```

两轮之内都**不得命中一条就 return**（round2 §5、round3 §4）。

## 四、尚未进入本模型的事实

以下问题树节点目前没有对应的 fact 路径，因为它们驱动的是**输出模板**
而不是法律规则，将在 P4 的文案数据文件中处理：

- G02 操作是否已生效（C00）
- G04 文件类型看不出（C19）
- B01 / B02 解除理由与首次出现时间（C17）
- C01–C03 协商解除路径（C01 / C02）
- D01–D04 事实解除路径（C03）
- A02 法定续延、A14 排除事由（C18 未覆盖）

时效相关路径已于 2026-09-04 定义，见 open-questions Q5：

| 路径 | 说明 |
| --- | --- |
| `scope.dispute_category` | 显式限定时效起算结论只在解除/终止争议内成立 |
| `operation.effective_status` | 操作未生效时不进入时效计算 |
| `procedure.limitation_interruption_events` | 中断事由；工具不因口头沟通自动认定中断 |
| `procedure.limitation_exceeds_one_calendar_year`（派生） | 按日历年，禁止 365 天 |

维护人明确：第二十七条第一款"知道或者应当知道其权利被侵害之日"的表述
更多指向**在职期间**的纠纷；解除、终止类争议原则上就是离职后一年内。
因此 P06 问法保持不变，但结论范围由 `scope.dispute_category` 锁死，
并以 `IN_SERVICE_DISPUTE`、`WAGE_ARREARS_SPECIAL_RULE` 两条例外阻断泛化。
