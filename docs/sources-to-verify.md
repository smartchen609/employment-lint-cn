# 待人工核验的法律来源

本文件由 CLAUDE.md §L1 产出：**规格书里没有给出的法律内容，一律不得由 AI 撰写**，
只能写 `TODO_VERIFY` 并登记到这里，由维护人人工核验。

核验动作的定义（round3 §8）：

> 每条法律依据的官方原文页，维护人亲自打开一次，核对
> **页面标题、制定机关、条文、施行日期和修改沿革**。

核验完成后，在 `sources.yml` 中把该条目的 `page_opened_and_checked` 改为 `true`，
并同时填写 `last_verified_at` 与 `verified_by`。
**在此之前，`npm run build` 会失败，这是设计行为。**

## B. 规格书未提供来源、但 P1 需要的规则

按 §L1，AI 不得自行补写法条名称、条文编号或 URL。**这些需要维护人先给出来源，
P1 才能落地。**

### ~~B1. 仲裁时效规则~~ —— 已于 2026-09-03 由维护人补齐

- 规格书要求：round2 §4.7 P06/P07、§7 R06、§12 T19 均依赖"劳动仲裁一般时效为一年，
  存在中断和中止"。
- 问题：round2 原本用脚注 **[6]** 支撑该规则，而 [6] **已被规格书自己确认为无效引用并禁止使用**。
  规格书正文没有给出替代的法律名称或条文编号。
- **已解决**：维护人指定《中华人民共和国劳动争议调解仲裁法》第二十七条，
  官方来源为中国人大网法律全文页，已登记为 `sources.yml` 中的 `CN-LDCA-2008`。
- **登记时的一项要求**：第二十七条**四款整体**收进 pinpoint，不得只录第一款。
  第二款（中断）、第三款（中止）是防止本工具机械输出"超过一年即失效"的结构性约束；
  第四款是拖欠劳动报酬的特别规则。
- 仍待维护人亲自打开该页核对后，才可将 `page_opened_and_checked` 置为 `true`。
